01 / 06

Сайт японского ресторана

Nagiwa

Задача
Ресторану нужен атмосферный сайт, который продаёт ужин ещё до визита.
Решение
Прелоадер и анимация первого экрана, меню с вкладками, галерея с лайтбоксом, кнопка Telegram и три языка.
Результат
Тёмная премиальная подача и меню, которое удобно листать одной рукой.
Типовой срок
3–7 дней
  • HTML
  • CSS
  • GSAP
  • i18n

02 / 06

Сайт фитнес-клуба

Vortaq

Задача
Клубу нужен сайт, который продаёт пробную тренировку и сразу передаёт заявку менеджеру.
Решение
Абонементы с расчётом выгоды, расписание по дням со свайпом, тренеры, галерея и форма заявки с защитой от спама.
Результат
В рабочей версии заявка уходит в Telegram менеджеру через серверную функцию. В демо форма работает в тестовом режиме.
Типовой срок
3–7 дней
  • JavaScript
  • Serverless
  • Lead form
  • i18n

03 / 06

Сайт кофейни

Brumelle

Задача
Кофейне нужна быстрая визитка: меню, часы работы и кнопка звонка прямо на первом экране.
Решение
Меню по категориям, карусель хитов, статус «открыто сейчас» по времени Ташкента, галерея с лайтбоксом и счётчики.
Результат
Код сайта весит около 100 КБ, фото подгружаются по мере прокрутки: открывается почти мгновенно даже на мобильном интернете.
Типовой срок
3–7 дней
  • HTML
  • CSS
  • JavaScript
  • i18n

04 / 06

Бронирование авиабилетов

SkyNavoi

Задача
Региональной авиакомпании нужен понятный путь покупки билета с телефона, без звонков в кассу.
Решение
Поиск рейсов, фильтры по цене, пересадкам и времени, выбор места на схеме салона, форма пассажира с проверкой и электронный билет.
Результат
Полный сценарий из 5 шагов на тестовых данных. Видео в шапке не грузится на медленном интернете и в режиме экономии трафика.
Типовой срок
4–8 недель
  • JavaScript
  • JSON data
  • sessionStorage
  • Video

05 / 06

Интерактивная карта ТЦ и админ-панель

Lumina Mall

Задача
Посетитель не может быстро найти магазин, а владельцу ТЦ нечем самому обновлять витрины, товары и фото.
Решение
Атриум на 4 этажа с лифтом и свайпом, поиск на трёх языках с транслитом и опечатками, страницы магазинов с корзиной и админ-панель.
Результат
Работает без сервера: данные и фото хранятся в браузере, есть экспорт и импорт. Облегчённый режим для слабых телефонов.
Типовой срок
4–8 недель
  • JavaScript
  • IndexedDB
  • Search
  • i18n
  • Admin

Пароль админки в демо: admin123

06 / 06

Интернет-магазин цветов

Lirevo

Задача
Заказы приходят в переписку, и каждый раз приходится вручную уточнять букет, адрес, время и текст открытки.
Решение
Каталог с категориями, поиском, фильтром цены и сортировкой. Корзина с отменой удаления и оформление по шагам: слоты доставки и промокод.
Результат
Клиент собирает заказ сам, а владелец получает его уже со всеми деталями. Три языка.
Типовой срок
2–4 недели
  • JavaScript
  • GSAP
  • Cart
  • Checkout
  • i18n
